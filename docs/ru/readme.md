# likha — Обзор

**likha** — это ReAct CLI-агент, написанный на TypeScript для Node.js. Он сочетает цикл ReAct (рассуждение + действие) с горячо подключаемыми ролевыми навыками и использует DeepSeek в качестве поставщика LLM по умолчанию. Бэкенд LLM управляется конфигурацией: DeepSeek — поставщик по умолчанию, а любой совместимый с OpenAI поставщик или Anthropic можно выбрать через `agent/config/llm.yaml` плюс одну переменную окружения для ключа API — **без изменения кода**. Этот документ является точкой входа в русскоязычный комплект документации.

## Обзор

likha — это CLI-агент, который следует паттерну **ReAct**: он итеративно обдумывает задачу, вызывает инструменты для сбора информации или внесения изменений, наблюдает за результатами и повторяет до тех пор, пока задача не будет выполнена. Он поддерживает несколько движков оркестрации, горячо подключаемые директивы навыков, поэтапное планирование, HTTP API-сервер, React-интерфейс и встроенный механизм самовосстановления, который обнаруживает, когда агент застрял.

Версия 0.2.0 поставляется с четырьмя взаимозаменяемыми движками оркестрации (`react` по умолчанию, `lean`, `langgraph`, `swarm`) и более чем 30 специализированными навыками, загружаемыми из `agent/skills/`.

## Ключевые возможности

- **Цикл ReAct** — фазы Поиск → Действие → Проверка
- **Несколько реализаций движков** — стандартный ReAct, LeanEngine, LangGraph и Swarm
- **Система навыков с горячим подключением** — более 30 специализированных навыков (programmer, architect, devops, tester и другие), загружаемых из `agent/skills/`
- **Режим Plan** — генерирует план задачи перед выполнением с одобрения пользователя
- **Поэтапное планирование** — делит сложные задачи на последовательные фазы с изолированным контекстом
- **Оценка здоровья с самовосстановлением** — обнаруживает остановку прогресса и возвращает агента на верный путь
- **HTTP API-сервер** — REST API на базе Express для удалённого выполнения задач
- **React-интерфейс** — фронтенд на Vite + TypeScript для управления задачами, планами и телеметрией

## Начало работы

Убедитесь, что `DEEPSEEK_API_KEY` задана в вашем окружении или в файле `.env`, затем установите зависимости и соберите проект:

```bash
npm run likha:install
npm run build
```

Запустите свою первую задачу:

```bash
npm start -- --task "Перечисли все файлы TypeScript в src/"
```

Не нужен шаг сборки? Вместо этого используйте dev-раннер:

```bash
npm run dev -- --task "Перечисли все файлы TypeScript в src/"
```
