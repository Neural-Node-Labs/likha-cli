# xcoder — نظرة عامة

**xcoder** هو وكيل سطر أوامر (CLI agent) يعمل بنمط ReAct، مكتوب بلغة TypeScript ويعمل على Node.js، ويتضمّن مهارات أدوار قابلة للربط السريع (hot-pluggable role skills)، ويستخدم DeepSeek كمزوّد LLM افتراضي. خلفية الـ LLM مدفوعة بالملفات: DeepSeek هو المزوّد الافتراضي، ويمكن اختيار أي مزوّد متوافق مع OpenAI أو Anthropic عبر `agent/config/llm.yaml` مع متغير بيئة واحد للمفتاح — **دون تغيير أي كود**. هذا المستند هو مدخل مجموعة التوثيق باللغة العربية.

## نظرة عامة

xcoder وكيل CLI يتبع نمط **ReAct** (Reasoning + Acting): فهو يفكّر في المهمة بشكل متكرّر، ويستدعي الأدوات لجمع المعلومات أو إجراء تغييرات، ثم يلاحظ النتائج، ويكرّر ذلك حتى اكتمال المهمة. يدعم الوكيل محرّكات تنسيق متعددة، وتوجيهات مهارات قابلة للربط السريع، وتخطيط المراحل (phase planning)، وخادم HTTP API، وواجهة React، وآلية شفاء ذاتي مدمجة تكتشف عندما يعلق الوكيل.

الإصدار 0.2.0 يتضمّن أربعة محركات تنسيق قابلة للتبديل (`react` الافتراضي، و`lean`، و`langgraph`، و`swarm`)، وأكثر من 30 مهارة متخصصة تُحمَّل من `agent/skills/`.

## الميزات الرئيسية

- **حلقة ReAct** — مراحل البحث ← التنفيذ ← التحقق
- **تطبيقات محركات متعددة** — ReAct القياسي، وLeanEngine، وLangGraph، وSwarm
- **نظام مهارات قابل للربط السريع** — 30+ مهارة متخصصة (programmer وarchitect وdevops وtester وغيرها) تُحمَّل من `agent/skills/`
- **وضع الخطة (Plan Mode)** — يولّد خطة مهمة قبل التنفيذ مع موافقة المستخدم
- **تخطيط المراحل (Phase Planning)** — يقسّم المهام المعقّدة إلى مراحل متتابعة بسياقات معزولة
- **تسجيل الصحة الشفائية الذاتية** — يكتشف توقف التقدم ويذكّر الوكيل بالعودة إلى المسار الصحيح
- **خادم HTTP API** — REST API مبني على Express لتنفيذ المهام عن بُعد
- **واجهة React** — واجهة أمامية مبنية على Vite + TypeScript لإدارة المهام والخطط والقياس عن بُعد (telemetry)

## البدء السريع

تأكد من ضبط `DEEPSEEK_API_KEY` في بيئتك أو في ملف `.env`، ثم ثبّت التبعيات وابنِ المشروع:

```bash
npm run xcoder:install
npm run build
```

نفّذ مهمتك الأولى:

```bash
npm start -- --task "سرد جميع ملفات TypeScript داخل src/"
```

لا تحتاج إلى خطوة بناء؟ استخدم مشغّل التطوير بدلاً من ذلك:

```bash
npm run dev -- --task "سرد جميع ملفات TypeScript داخل src/"
```
