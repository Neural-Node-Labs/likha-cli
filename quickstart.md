
# Quickstart

## Install dependencies
```

npm install

```

## Build the project
```
npm run build
```

## Link the CLI globally
```
npm link
```

## Run a task through the built CLI
```
xcoder --task "List all TypeScript files in src/"
```

# Build UI and run the web interface
```
npm run xcoder:install
npm run xcoder:build
npm link
xcoder --ui
```
# Run a task through the CLI

``
xcoder --task "List all TypeScript files in src/" --auto
``
